Bots

Each bot has its own personality and its own private memory, fed by its folder. Every bot can also use the shared memories. Bots never see each other's private memories — not even in Council.

➕ Add a bot

In File Explorer, right-click the bot's folder → Copy as path. Everything in it (subfolders too) becomes that bot's private memory. A file in it named like persona, personality, identity or instructions (.txt/.md) is used as the starting personality.

How to use Nuero AI

💬 Conversations

  • Pick who to talk to in the left sidebar: Nuero AI (main assistant, shared memories), any bot, or the Council.
  • Each conversation is kept separately in this browser, and the AI sees its last few messages, so follow-up questions work. Clear starts fresh.
  • Before answering, the AI looks up the 3 memories most related to your message. memories used under a reply shows them.

🏛 Council

  • Your message goes to several bots at once; each answer fills in as that bot finishes.
  • Members ▾ chooses who's in. Each bot answers from its own private memories plus shared ones.
  • One AI request per bot — if the service starts refusing (rate limit), pick fewer members.

🤖 Bots

  • Create bots in 🤖 Bots from their folders. Edit each personality there — it's the bot's instructions.
  • Save as memory saves into whoever you're talking to.
  • Picture: upload a photo or click 🎨 Create to have the image AI paint a portrait from the personality.
  • 🔊 Voice: give each bot its own voice, speed and pitch (▶ Preview). ⭐ voices are the natural-sounding ones — Microsoft Edge has the best free selection. Voice choices are saved in this browser.
  • 🧩 Skills: add named abilities to a bot (write them, or import a .md/.txt skill file). In the chat, pick one from the 🧩 menu in the header; switch any time.

📚 Library

  • Open 📚 Library in the sidebar: your books on a shelf, plus each bot's own archive where it keeps what it decides is important.
  • Add pages with 📚 Save to library under any reply, memory or image; or inside a book, Write a page or Add from memories (search everything, add a piece or a whole file).
  • 📎 Use in a conversation (or the 📚 button by the message box) attaches books: the AI then reads them in full with every message.

🧠 AI service

  • Choose Gemini, Claude, Grok or Ollama (local) and the model at the bottom-left; every bot uses it. Claude: Haiku (fast) → Sonnet → Opus (heavy lifting).
  • A service is offered once its key is set (GEMINI_API_KEY, ANTHROPIC_API_KEY, XAI_API_KEY), e.g. in PowerShell:
    [Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "your-key", "User")
    then open a new terminal and restart.
  • Only the relevant memories and recent messages are sent, with names and addresses masked.
  • 🔒 Ollama (local) runs AI models on this computer — nothing leaves the machine and it works offline. Start Ollama, then pick it and a model you've installed (ollama pull llama3.2). Bots don't create images on their own while it's selected. For full privacy, also leave 🎤 off (the browser transcribes speech online) and use voices without ⭐ (those stream from Microsoft).

🎨 Images

  • Type a description and click 🎨 (or type /image a lighthouse at dusk) to create a picture.
  • Bots can also create images on their own when they think a picture helps — shown in their reply with the prompt they wrote. Turn this on/off per bot, and set a daily limit, in 🤖 Bots. Never in Council.
  • Images are saved on this computer (see 🧠 Memory), and bots remember what they made.
  • Needs a Gemini or Grok key — Claude can't create images. Each image costs a few cents.

🎤 Voice

  • 🎤 to speak a message (Chrome or Edge; the browser sends audio to Google/Microsoft to transcribe). Voice reads replies aloud.

⚙️ Running

  • Start with start_nuero.bat. Stop by typing exit in its terminal.
  • Terminal commands: /ai, /bot, /bot Name, /council question.
  • Only one copy can run at a time.
